# 呼和浩特住宿與內蒙古交通清單

以隔天的高鐵或航班為起點比較呼和浩特東站區與新華廣場，留下可列印的行前查核清單。白塔與盛樂的機場名稱及路線須逐段確認。

白塔機場資料保留作舊路線辨識。聯合公告擬於 2026 年 11 月 26 日零時轉場至盛樂，跨日期行程請逐段確認機票及當日公告。

## 資料與工具

| 分類 | 站點 | 方式 | 出發前核對 |
|---|---|---|---|
| 白塔機場舊路線 | 壩堰（機場）→ 呼和浩特東 | 呼和浩特地鐵 1 號線 | 僅供核對白塔機場路線。盛樂轉場後請依航班資訊重新安排接駁。 |
| 白塔機場舊路線 | 壩堰（機場）→ 新華廣場 | 呼和浩特地鐵 1 號線 | 先按住宿地址核對地鐵站與出口，再估算步行。 |
| 盛樂轉場 | 盛樂國際機場 | 依航班與官方公告查核 | 公告擬於 2026-11-26 零時轉場，前後航班逐段核對，新機場交通依營運方公告。 |
| 北京出發 | 清河 → 呼和浩特東 | 城際鐵路 | 在 12306 輸入清河及日期，核對車票站名。 |
| 北京出發 | 北京北 → 呼和浩特東 | 城際鐵路 | 同時查清河選項，按出發地安排到站時間。 |
| 站區住宿 | 呼和浩特東站區 | 住宿區域比較 | 隔天從東站出發時，核對旅館到車站入口的實際步行路徑。 |
| 站區住宿 | 新華廣場站區 | 住宿區域比較 | 規劃市區地鐵移動時，核對最近入口及帶行李的路線。 |

[下載 CSV](travel-data.csv)。欄位包括交通分類、站點、方式、行前查核事項、來源與核對日期。需要票價、班次或無障礙動線時，請在出發前查相應營運方。

## 使用方式

執行 `python3 plan.py "站區住宿"`，或省略條件列出全部。工具使用 Python 3 標準函式庫。
